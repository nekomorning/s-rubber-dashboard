  • 一、国产（趋势项）分析框架
    • 产能结构：
      • 丁二烯：中石油 18%中石化 30%民营一体化 23%民营外销 25% → 流通货源占比提升
      • 顺丁：中石油 22%中石化 22%民营一体化 34%民营外采 22% → 外采丁二烯占比提升
    • 开工率：
      • 丁二烯：副产品，取决于乙烯开工
      • 顺丁：民营外采开工波动大；作为丁二烯几大下游中的调节项，消化过剩丁二烯
      • 跟踪路标：PE-原油、PE-石脑油、丁二烯-石脑油、BR-丁二烯价差；原油、石脑油基差裂差（石脑油是核心）；装置检修
  • 二、海外贸易（波动项）分析框架
    • 年度变化主线：能源危机+轮胎产业转移 → 韩、欧退，中国替代韩国，东南亚轮胎高增
      • 中：产能投放 → 国产替代+出口导向+汽车轮胎产业链优势，趋势性替代韩国角色，贸易量级变大，中间品转净出口
      • 东南亚：轮胎产业转移 → 轮胎出口高增，合成胶进口总量增（从中国增，从韩国减），丁二烯产能投放出口中国
      • 韩：供应链绑定没有优势，主动退出 → 轮胎-合成-丁二烯贸易流有萎缩
      • 欧：22年俄乌冲突能源危机 → 产能退出，中间品贸易萎缩，直接进口成品
    • 跟踪路标：丁二烯海外价格价差；全球乙烯检修；顺丁出口利润；石脑油、丁二烯、合成胶、轮胎进出口贸易流
  • 三、 26 年至今变化
    • 3 月海峡封锁 → 全球缺原料减产 → 优先满足海外需求，中国补海外缺口：① 丁二烯净出口给韩国消化库存；② 下游负反馈减需求（供需双减）
    • 期间冲突缓和 → 丁二烯产量稳定，下游顺丁等利润修复提开工，中国继续消化丁二烯库存（供平需增）
    • 7 月再次封锁 → 偏低库存下中国丁二烯领涨，检修装置重启增产；终端半钢淡季+库存压力降开工，需求难以承接（供增需弱）
    • 26.1-7 月累计数据（数字单位：万吨）
      • 丁二烯：中国产量+15， 进口-12（各国都减），出口+12（主要给韩国） → 预期未来进口逐步增，出口减（需要看到海峡解封，海外提负）
      • 顺丁：中国顺丁产量+1，出口+9（给东南亚，出口利润好），东南亚从中国进口增，从韩国减 → 长期趋势，轮胎生产向东南亚产业转移
      • 半钢胎：中国产量累计-0.2%，7 月环比-13%（库存压力大），出口+3.1% ，东南亚出口+19% → 长期趋势，欧美贸易壁垒
  • 四、后市展望（偏空）
    • 路径：① 海外丁二烯增产→中国增进口+增产（但石脑油强→增产有限）；②BR-丁二烯利润不大幅走扩（√）； ③ 全球轮胎增速不高（√）
    • 风险：海外丁二烯缺+合成胶需求好 → 中国出口高增弱化了供需矛盾（即外需消化了过剩） → BR 被海外轮胎定价（路标：顺丁提开工，√）
  • 五、本周变化（8.3）
    • 石脑油：冲高回落，乙烯裂解出现负反馈，供需双减 → 乙烯重启不及预期 → 全球丁二烯增产不及预期 → 中国丁二烯进口增量有限
    • 丁二烯：① 全球增产不及预期；② 国内前期检修装置重启，丁二烯提开工增产；③ 港口库存高位，企业库存偏低； ④ 内外价差高位回落
    • 顺丁：①装置能开尽开， 开工回升；② 货不缺，仓单快速注册，下游采买清淡；③ BR-丁二烯价差走弱
    • 半钢：渠道及工厂库存压力大，轮胎厂需要降开工去库存，需求减量预计每月 0.8wt 丁二烯（占月消费 1.5%），0.4wt 顺丁（占月消费3.3%）
